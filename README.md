# Western Vintage Showcase

Build a modern portfolio website called "Western Vintage" with a clean, editorial, dashboard-style interface.

Branding:

Use the uploaded "Western Vintage" logo (yellow/gold script wordmark on transparent background) as the primary logo in the navbar/header and as a hero focal point.

Color palette: warm gold/mustard yellow (#F5BE4C or similar, matched to the logo) as the primary accent, paired with deep charcoal/black (#1A1A1A) and off-white/cream (#F5F1E8) backgrounds — a vintage, retro-Americana aesthetic.

Typography: pair a bold vintage-inspired display font (for headings) with a clean modern sans-serif (for body text) to balance the retro logo with a contemporary layout.

Layout — Portfolio/Dashboard style:

Sidebar or top navbar with the logo, and nav links: Home, Portfolio, About, Services, Contact.

Hero section — large display of the Western Vintage logo, a short tagline, and a CTA button ("View Work" / "Get in Touch").

Dashboard-style portfolio grid — a masonry or card-based grid layout showing project thumbnails (image + title + category tag), similar to a creative dashboard/gallery view, with hover effects (zoom or overlay reveal).

Filter/category tabs above the grid (e.g., All, Photography, Branding, Products) to sort portfolio items dynamically.

About section — short bio/brand story with an image alongside text.

Stats or highlights strip — small dashboard-like cards showing key numbers (e.g., years active, projects completed, clients).

Contact section — simple form (name, email, message) with social links.

Footer — logo, copyright, social icons.

Style notes:

Rounded cards with subtle shadows, generous whitespace, smooth hover/scroll animations.

Fully responsive (mobile-first).

Keep the interface feeling like a curated dashboard/gallery rather than a static brochure site — interactive filtering, smooth transitions between sections.
